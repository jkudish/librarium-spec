# librarium-spec

The shared contract for Librarium: request, Run and stored-Run schemas, the source catalog (`sources.json`), and conformance fixtures used by both [librarium](https://github.com/jkudish/librarium) (JavaScript) and [laravel-ai-librarium](https://github.com/jkudish/laravel-ai-librarium) (Laravel).

Data and tests only; no runtime code. See [SPEC.md](SPEC.md).

Status: in development for Librarium JS 2.0 and Laravel AI Librarium 1.0.
